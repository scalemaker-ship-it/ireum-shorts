## A안 — 「김구가 찍고 싶었던 장면」 (감정형)

**훅 전략**: 결론의 한 조각을 먼저 던진다. "이 장면"이 무엇인지 끝까지 궁금하게 두고, 24초에 답한다.
**공유 장치**: "김구가 영화로 찍고 싶었던 장면" — 한 줄로 전하기 쉽고, 들은 사람이 "무슨 장면인데?" 하고 묻게 되는 문장이다.

| 컷 | 자막 / 나레이션 | 이미지 |
|---|---|---|
| 01 훅 | 김구는 이 장면을 / *영화로* 찍어 남기고 싶었다고 적었습니다. | 산길(chu_09) 빠른 줌인 |
| 02 | 1932년, 윤봉길 의거 뒤 / 일본은 김구의 목에 / *60만 원*을 걸었습니다. | 현상금 벽보(chu_02) |
| 03 | 그를 숨겨 준 사람은 / *조선 사람*이 아니었습니다. / 중국 저장성의 정계 원로였습니다. | 서재(chu_04) |
| 04 | 그는 고향 자싱에 / 김구가 숨을 곳을 *마련했습니다*. | 운하 마을(chu_06) |
| 04b | 김구는 수양아들의 집에 숨어 / *광둥 사람*으로 행세했습니다. | 호수(chu_11) |
| 05 | 그리고 그의 *며느리*가 / 김구를 데리고 산길을 넘었습니다. | 산길(chu_09) |
| 05b | 한여름 더위 속에, / *굽 높은 구두*를 신고서였습니다. | 기차·들판(chu_05) |
| 05c | 김구가 영화로 남기고 싶었던 장면은 / *바로 이것*이었습니다. | 편지(chu_12), 속도 늦춤 |
| 06 | 대한민국은 1996년, / 그에게 *건국훈장*을 추서했습니다. | 나룻배(chu_08) |
| 06b | 하지만 우리는 / 그의 이름을 *거의 모릅니다*. | 거리(chu_03) |
| 이름 | [암전] 오늘 우리가 다시 부를 이름. **추푸청** | 초상 |

- 약 270자 · 예상 **37~38초**
- 01과 05c가 짝이다. 첫 문장이 연 궁금증을 05c가 닫고, 그 여운 위에서 이름이 나온다.
- 근거: 01·05c ← 『백범일지』 "영화로 찍어 만대 후손에게 전할 마음이 간절하였다" (간접 인용) / 05b ← "굽 높은 구두를 신고 … 7, 8월 염천에"

## B안 — 「한 집안이 나섰다」 (반전형)

**훅 전략**: 스케일로 연다. '한 사람'이 아니라 '한 집안'이라는 말에서 궁금증이 생긴다. 이어서 가족을 한 명씩 호명하듯 쌓는다.
**공유 장치**: 마지막 반전 — "이 집안에서 훈장을 받은 사람은 단 한 명입니다." 고마움과 아쉬움이 같이 남아 댓글("나머지 가족도 기억해야")과 공유를 부른다.

| 컷 | 자막 / 나레이션 | 이미지 |
|---|---|---|
| 01 훅 | 김구 한 사람을 숨기려고 / *한 중국인 집안*이 나섰습니다. | 호수 정자(chu_11) 빠른 줌인 |
| 02 | 1932년, 윤봉길 의거 뒤 / 일본은 김구의 목에 / *60만 원*을 걸었습니다. | 현상금 벽보(chu_02) |
| 03 | *아버지*는 / 고향 자싱에 / 김구가 숨을 곳을 마련했습니다. | 운하 마을(chu_06) |
| 03b | *수양아들*의 집이 / 은신처가 됐고, / 김구는 광둥 사람으로 행세했습니다. | 서재(chu_04) |
| 04 | *며느리*는 굽 높은 구두를 신고 / 한여름 산길을 넘어 / 김구를 데려갔습니다. | 산길(chu_09) |
| 04b | 도착한 곳은 / *며느리 집안*의 별장이었습니다. | 별장(chu_10) |
| 05 | 김구는 훗날 그 산길을 / *영화로* 찍어 남기고 싶었다고 적었습니다. | 편지(chu_12), 속도 늦춤 |
| 05b | 대한민국이 훈장을 준 사람은 / 이 집안에서 *단 한 명*입니다. | 나룻배(chu_08) |
| 05c | 김구를 숨겨 준 그 아버지. / 우리는 그 이름을 *거의 모릅니다*. | 거리(chu_03) |
| 이름 | [암전] 오늘 우리가 다시 부를 이름. **추푸청** | 초상 |

- 약 290자 · 예상 **39~40초**
- 가족을 '아버지·수양아들·며느리·며느리 집안'으로만 부른다. 이름은 추푸청 하나만 공개한다(포맷 유지). 며느리 이름은 한자 표기가 셋으로 갈려 어차피 부를 수 없다.
- 근거: 05b ← 공훈전자사료관 외국인 포상자 목록 전수 조회(2026-09-24): 褚·朱·陳 성씨 중 추푸청 외 가족 **없음**. 서울신문(2024): "주자루이(며느리)에 대한 포상은 이뤄지지 않았다"
- ⚠️ "나섰습니다"는 가족이 **직접 한 일**(은신처 마련·집·안내·별장)만 가리킨다. 동기나 결의는 쓰지 않았다.
- ⚠️ 05b는 "받지 못했다"가 아니라 "단 한 명"으로 썼다. 포상 신청 여부까지는 확인하지 않았다.
